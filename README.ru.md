# Сообщество NewSocOps

Добро пожаловать в репозиторий сообщества NewSocOps! Это центральный узел для наших инициатив сообщества с открытым исходным кодом, грантовых программ и совместных проектов.

## Миссия

NewSocOps посвящена поддержке и расширению возможностей проектов с открытым исходным кодом и участников через прозрачное управление сообществом и устойчивые механизмы финансирования.

## Спонсоры

Мы благодарны за поддержку наших спонсоров, которые делают это сообщество возможным. Посмотрите наших текущих спонсоров и узнайте, как стать одним из них, на странице [SPONSORS.md](SPONSORS.md).

## Прозрачность

Прозрачность является основной ценностью NewSocOps. Мы ведем публичные записи:

- **Распределение грантов**: Просмотрите нашу полную [историю распределения](allocation-history.md)
- **Ежемесячные отчеты**: Проверьте директорию [reports](reports/) для подробных ежемесячных обновлений
- **Процесс принятия решений**: Узнайте о нашем [процессе грантов](docs/grants-process.md)

## Примите участие

- **Подать заявку на грант**: См. [документацию процесса грантов](docs/grants-process.md)
- **Внести вклад**: Прочитайте наши [рекомендации по участию](CONTRIBUTING.md)
- **Сообщить о проблемах**: Используйте наши шаблоны для подачи заявок на гранты или сообщения о проблемах

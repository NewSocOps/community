# NewSocOps 社区

欢迎来到 NewSocOps 社区仓库！这是我们开源社区倡议、资助项目和协作项目的中心枢纽。

## 使命

NewSocOps 致力于通过透明的社区治理和可持续的资助机制来支持和赋能开源项目和贡献者。

## 赞助商

我们感谢赞助商的支持，是他们让这个社区成为可能。在 [SPONSORS.md](SPONSORS.md) 页面查看我们当前的赞助商并了解如何成为赞助商。

## 透明度

透明度是 NewSocOps 的核心价值。我们维护以下公开记录：

- **资助分配**: 查看我们完整的[分配历史](allocation-history.md)
- **月度报告**: 查看 [reports](reports/) 目录获取详细的月度更新
- **决策流程**: 了解我们的[资助流程](docs/grants-process.md)

## 参与其中

- **申请资助**: 查看我们的[资助流程文档](docs/grants-process.md)
- **贡献**: 阅读我们的[贡献指南](CONTRIBUTING.md)
- **报告问题**: 使用我们的问题模板提交资助申请或报告问题

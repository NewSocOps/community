## Allocation Format

Each allocation entry includes:
- **Date**: When the allocation was approved
- **Project**: Name and link to the project
- **Amount**: Funds allocated (USD)
- **Purpose**: Brief description of what the funds support
- **Status**: Current status (Approved, In Progress, Completed)
- **Report**: Link to relevant report or update
